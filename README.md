# Projeto de Parceria | Semantix

## Análise de satisfação no e-commerce

Projeto desenvolvido como parte da formação em Análise de Dados da EBAC, no contexto do Projeto de Parceria com a Semantix.

### Objetivo

Analisar fatores relacionados à insatisfação de clientes no e-commerce e desenvolver um modelo preditivo capaz de identificar pedidos com maior probabilidade de resultar em avaliações negativas.
